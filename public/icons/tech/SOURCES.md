# Technology icon sources

Devicon SVGs: https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons

Files: java, csharp, typescript, javascript, python, powershell, yaml, angular, react, spring, dotnetcore, postgresql, docker, kubernetes, terraform, githubactions, amazonwebservices, azure. These are the original variants, with the original-wordmark variant for AWS. See DEVICON-LICENSE.txt.

LangChain and LangGraph: https://github.com/simple-icons/simple-icons/tree/98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d/icons

See SIMPLE-ICONS-LICENSE.txt. LangChain, LangGraph, and YAML are displayed in a light monochrome treatment for contrast on dark surfaces. AWS uses a light icon backing for wordmark readability. Source files are unmodified.

SQL is represented by a generic database SVG authored for this project, since SQL is a language rather than one vendor's product.

Names and logos identify the listed technologies; they do not indicate endorsement.
